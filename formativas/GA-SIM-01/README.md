## 1. Descripción de la actividad

La actividad consiste en realizar una simulación de priorización y negociación de requisitos entre diferentes partes interesadas, utilizando el caso de estudio «Inscripciones universitarias» proporcionado por el docente.

Se aplicarán las técnicas de priorización MoSCoW y votación ponderada, así como la identificación y resolución de conflictos mediante acuerdos win-win.

## 2. Objetivo

Aplicar técnicas de priorización y negociación de requisitos para establecer acuerdos fundamentados entre las partes interesadas, considerando el valor de negocio, los riesgos técnicos, el esfuerzo de implementación y las restricciones del caso de estudio.

## 3. Caso de estudio

**Sistema de Inscripciones Universitarias**

El caso plantea la implementación de un sistema web de inscripciones universitarias que sustituya los procedimientos realizados mediante formularios en papel y hojas de cálculo.

El grupo trabajará con los diez requisitos candidatos establecidos en la guía oficial:

| R-02 | Validación automática de prerrequisitos y cupos. |
| R-03 | Pago de matrícula en línea. |

| R-08 | Aplicación móvil nativa para Android e iOS. |
| R-09 | Consulta de reportes de inscritos. |

## 5. Desarrollo de la actividad

### 5.1. Presentación de posiciones

Cada integrante deberá presentar y defender de manera independiente la posición correspondiente a su rol asignado.

### 5.2. Priorización MoSCoW

El grupo clasificará los diez requisitos mediante las siguientes categorías:

- **Must Have (M):** imprescindible.
- **Should Have (S):** importante.
- **Could Have (C):** deseable.
- **Won't Have (W):** fuera de esta entrega.

Se utilizarán las cuatro categorías y cada clasificación deberá justificarse considerando los datos del caso, las posiciones de los roles y las dependencias entre requisitos.

Ningún requisito clasificado como Must deberá depender de otro requisito con menor prioridad.

### 5.3. Votación ponderada

Cada requisito será evaluado mediante tres criterios:

| Criterio | Peso |
|---|---:|
| Valor de negocio (V) | 40 % |
| Riesgo técnico (R) | 30 % |
| Esfuerzo (E) | 30 % |
| **Total** | **100 %** |

Se utilizará una escala de 1 a 5, considerando una puntuación inversa para el riesgo técnico y el esfuerzo, donde 5 representa un riesgo o esfuerzo bajo.

La fórmula para calcular el puntaje ponderado será:

**P = 0,40V + 0,30R + 0,30E**

Los requisitos se ordenarán de mayor a menor puntaje y se explicarán las diferencias respecto a la clasificación MoSCoW.

### 5.4. Identificación y resolución de conflictos

Se documentarán al menos dos conflictos ocurridos durante la sesión de negociación, considerando:

- Requisitos involucrados.
- Roles implicados.
- Posición de cada rol.
- Tipo de conflicto.
- Acuerdo alcanzado.
- Cesiones y beneficios de cada rol.

Los tipos de conflicto considerados serán:

- De intereses.
- De datos.
- De valores.
- Estructural.
- De relación.

Los acuerdos deberán aplicar el enfoque win-win, establecer cesiones recíprocas y respetar las exigencias normativas y de protección de datos.

Los acuerdos alcanzados deberán reflejarse en la tabla MoSCoW.
