# 03 - Rivas

## Responsable
**Rivas**

## Actividad
GA-PRAC-01 - Comparación entre modelos de proceso de requisitos en escenarios reales.

## Responsabilidades asignadas

### C4. Recomendación fundamentada del modelo (2,5 puntos)

- Analizar los resultados de la matriz comparativa.
- Seleccionar el modelo de proceso de requisitos más adecuado para el escenario asignado.
- Justificar la elección mediante al menos tres razones válidas derivadas del escenario.
- Explicar por qué los otros dos modelos no son los más adecuados.
- Utilizar terminología precisa de Ingeniería de Requisitos.

### C5. Análisis de riesgos del modelo elegido (1,0 punto)

- Identificar los riesgos específicos asociados al modelo seleccionado.
- Explicar cómo podrían afectar al desarrollo del sistema.
- Proponer medidas de mitigación para cada riesgo identificado.
- Relacionar los riesgos con las características del escenario asignado.
