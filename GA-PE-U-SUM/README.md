# GA-PE-U · SUM — Práctica Experimental Unidad I

**Asignatura:** Ingeniería de Requisitos (ISR-401)  
**Unidad:** I — Proceso de requisitos  
**Actividad:** GA-PE-U · SUM  
**Sistema seleccionado:** Plataforma de Comercio Electrónico de Almacenes Tía (https://www.tia.com.ec/)

## Objetivo

Aplicar el proceso de Ingeniería de Requisitos a la plataforma de comercio electrónico de Almacenes Tía, mediante la identificación, clasificación, análisis, especificación y validación de requisitos, considerando los lineamientos de Pohl, ISO/IEC/IEEE 29148 y SWEBOK v4.

### 1. Córdova Carreño Mayra Lucila

- Contexto local y problemática.
- Identificación de al menos 15 requisitos.
- Clasificación y justificación de RF, RNF y restricciones.
