## Responsabilidades asignadas

### 1. Propiedades de calidad
Evaluar cada uno de los requisitos identificados
conforme a ISO/IEC/IEEE 29148.

Considerar las propiedades aplicables:
- Necesidad.
- Ausencia de ambigüedad.
- Completitud.
- Consistencia.
- Verificabilidad.
- Factibilidad.
- Trazabilidad.
- Singularidad.

### 2. Matriz de evaluación
Elaborar una matriz para los 15 requisitos.

Incluir:
- Identificador del requisito.
- Propiedades evaluadas.
- Resultado de la evaluación.
- Justificación verificable.
- Observaciones o correcciones necesarias.

### 3. Actores del proceso
Identificar:
- Ingeniero de requisitos.
- Cliente.
- Usuario.
- Desarrollador.

### 4. Roles y responsabilidades
- Explicar la función de cada actor.
- Relacionar sus responsabilidades con el sistema.
- Diferenciar actores reales de roles propuestos.

### 5. Evidencias
- Matriz de evaluación de calidad.
- Justificaciones de las propiedades.
- Fuentes utilizadas.
