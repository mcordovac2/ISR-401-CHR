## Responsabilidades asignadas

### 1. Introducción y descripción del sistema
- Presentar el sistema seleccionado.
- Describir su propósito y funcionamiento.
- Identificar el contexto local de aplicación.
- Explicar la problemática y las necesidades.

### 2. Identificación de requisitos
- Identificar al menos 15 requisitos únicos.
- Asignar identificadores a cada requisito.
- Redactar los requisitos de forma clara.

### 3. Clasificación de requisitos
- Identificar requisitos funcionales (RF).
- Identificar requisitos no funcionales (RNF).
- Identificar restricciones (RES).
- Justificar cada clasificación.
- Cuantificar los requisitos no funcionales.

### 4. Matriz de requisitos
Elaborar una matriz que contenga:
- Identificador.
- Descripción del requisito.
- Tipo de requisito.
- Justificación.
- Evidencia o fuente.

### 5. Evidencias
- Capturas de pantalla del sistema.
- Registro de funcionalidades observadas.
- Identificación de requisitos propuestos.
