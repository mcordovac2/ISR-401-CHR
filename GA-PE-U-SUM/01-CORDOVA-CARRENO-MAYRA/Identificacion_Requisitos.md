## 3. DESCRIPCIÓN DEL SISTEMA

**Nombre:** Plataforma de Comercio Electrónico de Almacenes Tía.

**Tipo:** Sistema web de comercio electrónico.

**Ámbito:** Comercial.

**Sitio web:** https://www.tia.com.ec/

**Contexto:** Ecuador, considerando como referencia local la tienda Tía ubicada en San Carlos, provincia de Los Ríos.

La plataforma de comercio electrónico de Almacenes Tía es un sistema web que permite a los clientes explorar productos comercializados por la empresa mediante una interfaz digital.

El sistema dispone de funcionalidades relacionadas con la búsqueda de productos, navegación por categorías, visualización de ofertas y gestión de un carrito de compras.

Para esta práctica experimental se realiza un análisis de las funcionalidades accesibles desde la perspectiva de un usuario de la plataforma, utilizando técnicas de observación directa.

### 3.1. Contexto local

El análisis se desarrolla tomando como referencia el contexto comercial de San Carlos, provincia de Los Ríos, Ecuador.

La plataforma permite seleccionar una tienda como referencia para la experiencia de compra. Durante la observación se identificó la tienda Tía San Carlos en la interfaz del sistema.

La utilización de este sistema representa un caso de estudio pertinente para Ingeniería de Requisitos, debido a que permite examinar funcionalidades de comercio electrónico utilizadas en un entorno comercial real.

El alcance de la práctica se limita a las funcionalidades exploradas por la estudiante, sin incluir la ejecución de compras ni la verificación de procesos internos de la empresa.

### 3.2. Problemática y necesidades identificadas

En un entorno comercial, los clientes necesitan mecanismos que faciliten la localización de productos, la consulta de información y la organización de artículos antes de realizar una compra.

A partir de este contexto, se identifican las siguientes necesidades para el análisis:

1. Facilitar la búsqueda de productos mediante una interfaz accesible.
2. Organizar los productos en categorías que permitan su localización.
3. Presentar información relevante sobre los artículos disponibles.
4. Permitir al usuario seleccionar productos de su interés.
5. Facilitar la administración de artículos dentro del carrito de compras.
6. Presentar promociones y ofertas de manera comprensible.
7. Permitir identificar la tienda seleccionada por el usuario.

Estas necesidades constituyen la base para la identificación y clasificación de requisitos del sistema.

### 3.3. Funcionalidades observadas

Durante la exploración de la plataforma se identificaron las siguientes funcionalidades:

| ID | Funcionalidad | Descripción |
|---|---|---|
| FO-01 | Búsqueda de productos | Permite localizar artículos mediante el buscador de la plataforma. |
| FO-02 | Navegación por categorías | Facilita la exploración de productos agrupados por categorías. |
| FO-03 | Visualización de productos | Presenta información de los artículos disponibles en el catálogo. |
| FO-04 | Carrito de compras | Permite agregar productos seleccionados a un carrito virtual. |
| FO-05 | Visualización de promociones | Presenta ofertas y campañas comerciales en la interfaz principal. |
| FO-06 | Selección de tienda | Muestra la tienda seleccionada como referencia para el usuario. |

**Delimitación de la observación:**

La exploración realizada comprende la navegación por la plataforma, búsqueda de productos y adición de artículos al carrito.

No se efectuaron compras, pagos electrónicos ni comprobaciones de procesos administrativos internos.

Por consiguiente, las funcionalidades no examinadas directamente deberán identificarse como pendientes de verificación.
