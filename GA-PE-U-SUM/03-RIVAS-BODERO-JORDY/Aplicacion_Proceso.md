## 4. APLICACIÓN DEL PROCESO DE REQUISITOS

### 4.1. Elicitación de requisitos

**Objetivo:** Identificar las necesidades de los usuarios y las funcionalidades del sistema.

**Técnicas seleccionadas:**
- Observación directa.
- Análisis de documentación.
- Entrevistas o cuestionarios, si se realizan.

**Evidencias obtenidas:**

*Pendiente de documentar.*

### 4.2. Análisis de requisitos

**Objetivo:** Examinar los requisitos identificados para determinar su consistencia, prioridad y viabilidad.

**Actividades:**
- Revisión de requisitos.
- Identificación de posibles conflictos.
- Priorización de requisitos.
- Análisis de dependencias.

**Artefactos obtenidos:**

*Pendiente de documentar.*

### 4.3. Especificación de requisitos

**Objetivo:** Documentar los requisitos mediante descripciones claras, identificadores únicos y criterios verificables.

**Artefactos:**
- Matriz de requisitos.
- Especificación de requisitos.
- Criterios de aceptación.

**Resultados:**

*Pendiente de documentar.*

### 4.4. Validación de requisitos

**Objetivo:** Comprobar que los requisitos documentados sean adecuados, claros, consistentes y verificables.

**Técnicas:**
- Revisión de requisitos.
- Listas de verificación.
- Contraste con las funcionalidades observadas.
- Consulta a usuarios, si se realiza.
